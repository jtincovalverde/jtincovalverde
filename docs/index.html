01 / Management mindset

Administration should improve the system, not only supervise it.

My approach starts with the operation itself: how information moves, where people wait, which tasks repeat, what creates errors and where management lacks visibility.

From there, I look for the simplest useful improvement — a better process, a KPI, a redesigned workflow, automation, software or a data-supported decision.

Technology is not the objective. Better execution is.
